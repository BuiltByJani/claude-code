# Copy this folder per brand: `cp -r _template your-brand`

```
your-brand/
  brand-dna.md        who, what, proof, banned words
  voice.md            built from 3 of your reels (required before any script)
  logo.svg
  product-images/     raw product photos
  studio-shots/       clean hero shots (section 4 prompts)
  characters/{name}/  face lock, outfit base, 6-panel sheet (same face every video)
  advertisements/{product}_{date}/{NN}-{angle}/  ad-spec.md (shot table) + renders
  ugc/{output-name}/  script, b-roll list, raw takes, final
  edits/{post-name}/  raw.mp4, captions.srt, final.mp4
```
